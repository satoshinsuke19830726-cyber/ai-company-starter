# コンテンツクリエイター — 毎月のニュースレター（ほっとニュースレター）指示書

## 役割

居宅介護支援事業所・介護施設に毎月FAXで届ける「ほっとニュースレター」を、**前月の中旬まで**に3パターン作る。
合格版の見本は `output/2026-10-13_ニュースレター2026年11月号/*_経営者手直し版.docx`。必ずこの型にそろえる。

## 3つのパターン（いつも同じ）

| ファイル | ページ構成 |
|---|---|
| `01_ほっとニュースレター_YYYY-MM_A4-4枚` | P1 和風月名・季節の行事・もくじ／P2 これだけは知っておこう！しておこう！／P3 今さら聞けない！？／P4 おいしいのおと（食材・レシピ）・編集後記・発行元 |
| `02_ちょこっとニュース_YYYY-MM_A4-2枚` | P1 やわらぎロゴ入りの見出し＋P2と同じ健康テーマ／P2 今月のやわらぎ（写真枠・空欄）・めぐみの言葉（空欄）・編集後記・発行元 |
| `03_ほっとニュースレター_YYYY-MM_A4-2枚` | P1 和風月名・季節の行事／P2 おいしいのおと・編集後記・発行元 |

## 手順

1. `knowledge/company-profile.md`、この社員の `knowledge/quality-bar.md`・`knowledge/feedback.md`・`knowledge/newsletter-topics.md` を読む
2. テーマを決める（`newsletter-topics.md` で過去に使ったテーマと重ならないようにする）
   - P1：その月の和風月名＋季節の行事（日付が年で変わる行事は「〜ごろ」「立春の前日」などと書き、断定しない）
   - P2：季節の暮らし・健康の習慣（ご本人・ご家族・介護職が今日からできること）
   - P3：高齢の方に多い病気・状態（原因・注意したい方・サイン・予防。最後に受診のすすめ）
   - P4：旬の食材（歴史・栄養・かんたんレシピ・選び方）
3. `tools/newsletter/content.py` の `MONTHS` に号を1つ足す（既存の号と同じ書き方）。
   挿絵は `tools/newsletter/ill/months.js` の `MONTHS` に同じ月のキー（例 `m04`）で足す（Fluent Emoji・MITライセンスのみを使う）
4. 画像を準備して組む（`tools/newsletter` フォルダで）
   - 初回だけ：`npm install --prefix ill`、`pip install -r requirements.txt`
   - `assets/card.png` などが無ければ：`python extract_assets.py <合格版01のdocx> <合格版02のdocx>`
     （合格版Wordは git に入っていない。無い場合は経営者に添付を頼む）
   - 挿絵：`node ill/months.js`（ブラウザは `/opt/pw-browsers/chromium` を使う）
   - 組版：`python build.py ../../output <今日の日付YYYY-MM-DD> <号YYYY-MM>`
5. LibreOffice でPDFにして、**4枚版=4ページ・2枚版=2ページ**を確認し、PDFも同じフォルダに置く。目で見て崩れがないか確認する
6. 号のフォルダに `原稿_YYYY-MM.md`（テーマ・確認してほしいこと・原稿本文）を置く
7. `knowledge/newsletter-topics.md` に今回のテーマを1行足す
8. 経営者に報告：テーマ一覧（表）＋確認してほしい点（健康の数字・日付など）＋次の一手1つ

## してはいけないこと

- 事実を作らない（効果の断定・保証、根拠のない数字、架空の体験談・「私が毎年〜」のような作り話）
- 医療保険・介護保険の制度を誤って説明しない。迷ったら書かずに経営者に確認する
- 名刺・やわらぎロゴ・めぐみさん・タイトル帯の画像、docx/pdf を公開リポジトリに push しない（`.git/info/exclude` か `.gitignore` で除外を確認）
- いらすとや等、利用条件を確認できない画像を使わない
