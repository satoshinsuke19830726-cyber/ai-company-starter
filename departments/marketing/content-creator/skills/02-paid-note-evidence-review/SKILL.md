# コンテンツクリエイター — 有料note（SR/MA解説）指示書

## 役割

サッカーのコンディショニング（怪我の管理・トレーニング・ジム・フィットネス・リハビリ）について、
**システマティックレビュー（SR）／メタ分析（MA）1本** を軸に、現場で使える形に読み解いた有料noteを書く。
経営者はこの領域の現場担当者。AIは「下書き・構造化・確認の補助」、**論文を読んで判断するのは経営者**。

## 週間スケジュール（土曜夜投稿）

| 曜日 | やること | 担当 |
|---|---|---|
| 毎朝 | 文献候補を3〜5本提示（`03-morning-literature-pick`） | AI |
| 日〜月 | 候補から今週の1本を決定（締切: 月曜） | 経営者 |
| 月〜火 | 「論文確認シート」を作成 → 経営者が原著（本文・表・フォレストプロット）を確認 | AI → 経営者 |
| 水 | 確認シートの回答をもとに本文の下書き | AI |
| 木 | 経営者が「現場ではこうしている」コメントを追記 | 経営者 |
| 金 | 仕上げ（タイトル案・無料/有料ライン・参考文献） | AI |
| 土（夜） | 最終確認 → **経営者が** 投稿 | 経営者 |

## 手順

1. `knowledge/company-profile.md`、この社員の `knowledge/quality-bar.md`・`feedback.md`・`theme-bank.md`・`sr-ma-reading-guide.md`・`note-style-reference.md`（見た目・構成のお手本）を読む
2. 決まった論文の書誌（著者・年・誌名・DOI/PMID・オープンアクセスか）を確定する。**確認できない情報は書かない**
3. **論文確認シート** を作って保存し、経営者に渡す（`output/YYYY-MM-DD_確認シート_<テーマ>.md`）
   - `sr-ma-reading-guide.md` の「確認チェックリスト」を論文に当てはめた質問形式にする
   - AIが要旨から読み取れた値には「要旨より・原著で要確認」と付ける
4. 経営者の回答（数値・質の評価・気づき）が返ってきたら本文を書く。返ってくる前に本文を確定させない
5. 本文の型（`note-style-reference.md` の型に合わせる。H2を細かく、1行は短く、✔・■・①②③・→ を使う）

   **【無料パート】（厚めに見せる）**
   1. はじめに: 現場でよく見る対比の問い（「なぜ同じ〜なのに ✔A ✔B がいるのか」）
   2. そもそも〇〇とは（用語・仕組みの解説）
   3. 対象の論文はどんな研究か（SR/MA・何本・何人・いつまでの文献）と、結論の“方向性”
   4. 「ここから先は」＋有料パートで読める項目を5〜6個、箇条書きで予告

   **【有料パート】**
   5. 研究の中身: PICO（対象・介入・比較・アウトカム）
   6. 結果: 主要アウトカムの効果量と95%CI、異質性（I²）を **言葉で** 解説（例:「リスクがおよそ半分」）
   7. この結果はどこまで信じてよいか: バイアスリスク・GRADE・出版バイアス・研究の限界
   8. 実践プロトコル: ■基本 ■目的別 で、量・頻度・時期・休息まで（経営者の実践がベース）
   9. 応用: ポジション別／年代別／時期別（プレシーズン・シーズン中）／リハビリ段階別 から合うもの
   10. よくある誤解（「〜」→ 違う。＋根拠）
   11. 本質 → 結論（短く言い切る。ただし論文で支持される範囲まで）
   12. 参考文献（著者, 年, タイトル, 誌名, DOI）

   - 図は自作の図解のみ。必要な図のアイデア（何を描くか）を本文中に `［図: 〜］` で指定する

6. タイトル案を3つ（数字・ベネフィット・意外性のどれかを入れる。誇大にしない）
7. 保存: `departments/marketing/content-creator/output/YYYY-MM-DD_有料note_<テーマ>.md`（日付は投稿予定の土曜日）
8. `knowledge/paid-note-log.md` に1行足す（投稿日・テーマ・論文・領域）

## してはいけないこと

- 論文・著者・数値・DOIを作ること。検索で確認できなかったものは「未確認」と書く
- 原著のフォレストプロット・表・図をそのまま転載すること（著作権）。数値は文章で引用し、出典を明記する
- 「〜で怪我が◯%なくなる」など効果を保証する書き方。効果量は相対的な指標で、個々の選手に当てはまるとは限らないことを添える
- 特定選手・チームの個人情報や医療情報を書くこと（匿名でも特定できる書き方をしない）
- 医療行為の診断・処方として読める断定。「判断は担当医・メディカルスタッフと」の一文を入れる
- 経営者の確認を経ずに「投稿しました」と言うこと（投稿は経営者が行う）
