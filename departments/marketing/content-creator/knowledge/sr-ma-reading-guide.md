# SR/MA 読み解きガイド（経営者の自己成長用・確認チェックリスト）

> 毎週の「論文確認シート」はこのチェックリストから作る。
> 目的は「AIの要約を信じる」ことではなく、**経営者が自分で原著を確認して判断できるようになる** こと。

## 確認チェックリスト（毎回この順で原著を見る）

### A. 問いと方法（Methods）
- [ ] 論文が撤回されていないか（PubMed・論文ページ・Retraction Watch）。訂正（erratum）が出ていないか
- [ ] PICO: 対象（年代・性別・競技レベル）／介入／比較／アウトカムは何か。自分のチームの選手に近いか
- [ ] プロトコル事前登録（PROSPERO 等）はあるか。登録内容と本文で変更はないか
- [ ] 報告ガイドライン（PRISMA 2020）に沿っているか。フロー図で何本から何本に絞られたか
- [ ] 検索したデータベースと検索期間（いつまでの論文か。最新の研究が漏れていないか）
- [ ] 組み入れた研究デザイン（RCTのみ？ コホートも混ぜている？）

### B. 個々の研究の質
- [ ] バイアスリスクの評価ツール（RoB 2・ROBINS-I・PEDroスケール等）と、その結果
- [ ] 質の低い研究を除いた感度分析で結論は変わるか

### C. 結果（Results）
- [ ] 効果指標は何か（RR・OR・IRR・SMD・MD）。それぞれの意味を自分の言葉で説明できるか
- [ ] 点推定値と95%信頼区間。区間が「効果なし（1 または 0）」をまたいでいないか
- [ ] 異質性: I²（目安 25/50/75%）・τ²・予測区間。バラつきの理由をサブグループ解析で説明しているか
- [ ] 固定効果 vs ランダム効果モデル、どちらを使っているか
- [ ] 出版バイアス: ファンネルプロット・Egger検定（研究数10本未満なら評価が難しい）
- [ ] 効果の大きさは現場で意味があるか（統計的に有意＝現場で重要、ではない）

### D. 確実性と結論
- [ ] GRADE（エビデンスの確実性: 高・中・低・非常に低）を評価しているか
- [ ] 著者の結論は、結果の強さに見合っているか（言い過ぎていないか）
- [ ] 利益相反・研究資金

### E. 現場への翻訳（ここが有料noteの価値）
- [ ] 自分のチームでやるなら、量・頻度・時期・誰に、をどうするか
- [ ] この論文で「まだ分からないこと」は何か
- [ ] 選手・監督に一言で伝えるなら？

## 用語メモ（読みながら増やす）

| 用語 | ひとことで | 現場の言い方の例 |
|---|---|---|
| RR（リスク比）0.5 | 起きる確率が半分 | 「やったチームは肉離れがおよそ半分」 |
| SMD 0.2/0.5/0.8 | 効果量 小/中/大 の目安 | 「効果は小さめだが確かにある」 |
| 95%CI | 真の値がありそうな幅 | 「少なくとも◯、多ければ◯くらい」 |
| I² | 研究間のバラつき | 「研究によって結果がかなり違う」 |
| GRADE | 結論をどれくらい信じてよいか | 「まだ“たぶん”の段階」 |
