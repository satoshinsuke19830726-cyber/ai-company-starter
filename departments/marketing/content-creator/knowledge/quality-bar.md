    # コンテンツクリエイター — 合格ライン（ナレッジ＝判断基準）

    > 仕事の前に必ず読む。ここが「この会社では何が良い成果物か」の基準。
    > 経営者が「これで合格」と言ったものは、`output/` の実物とあわせてここに1行足していく。

    ## 会社共通（全AI社員）

    - [ ] `knowledge/company-profile.md`（会社の憲法）の事業内容・ターゲット・トーンが反映されている
    - [ ] 事実が分からないこと（価格・実績・日付）は作らず `TBD` と書いて経営者に確認している
    - [ ] 誇大表現・保証できない数字（「絶対儲かる」など）が無い

    ## この社員の基準

    - [ ] 冒頭で結論（読むメリット）を言えているか
- [ ] 具体例が最低1つ入っているか
- [ ] ターゲットが明日できる行動で終わっているか

## 有料note（SR/MA解説）の合格ライン

- [ ] 軸になる SR/MA が1本に絞られ、書誌（著者・年・誌名・DOI）がすべて確認済み
- [ ] 数値は経営者が原著で確認したもの（「要旨より」の値が残っていない）
- [ ] PICO・効果量と95%CI・異質性・バイアスリスク／GRADE・限界が書かれている
- [ ] 統計の言葉を、現場の言葉に言い換えている（例: RR 0.5 →「およそ半分」）
- [ ] 経営者自身の現場での実践・判断が入っている（論文要約だけで終わらない＝有料の価値）
- [ ] 無料パートで「何が分かるか」が明確で、有料パートに具体策がある
- [ ] 図表の転載がない／効果を保証する表現がない／選手が特定される記述がない
- [ ] 「最終判断は担当医・メディカルスタッフと」の一文がある
